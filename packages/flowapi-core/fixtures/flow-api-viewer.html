Pick or paste a Mermaid sequenceDiagram and an OpenAPI 3.x file (YAML or JSON). You can also drop both files anywhere on the page. Nothing is uploaded; it all stays in this browser.

How arrows are linked to endpoints
  • Spec file: put %% @oai-doc kx-sign-openapi.yaml at the top of the .mmd. With ?flow=path/to/flow.mmd the viewer loads that spec by itself (needs a web server, not file://).
  • Exact link: put %% @api A1 on the line above an arrow. It matches the operation's x-diagram-tag: A1 (must be unique in the spec) or, failing that, its operationId. Mermaid ignores these comments, so the diagram renders cleanly anywhere.
  • Old style: [A1] at the start of the arrow text still works.
  • By path (guess): arrow text containing POST /v1/things/{id} is matched to that method and path. A leading … matches the end of a path. Shown with a dashed tag.
  • Replies (guess): an untagged dashed reply going straight back right after a linked call is linked to the same endpoint. Also dashed.
  • Operations without a link still get a grey card. The Checks panel lists every miss.
  • Optional: info.x-doc-links maps a section name in x-doc-sections to a URL, so the chips become links.
